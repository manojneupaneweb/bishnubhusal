# Bed Prasad Bhusal - Professional Portfolio

## Overview
This project is a professional portfolio website created for **Bed Prasad Bhusal**, a seasoned business professional and Managing Director of **B&B Group Pvt. Ltd.**, Nepal's leading supplier of surgical and medical equipment. The portfolio also highlights his role as Chairman of **Sachetana Media Pvt. Ltd.**. The website is designed to showcase his expertise, services, and contact information in an elegant and user-friendly manner.

---

## Features
### 1. **Hero Section**
   - Full-screen hero image with a professional profile picture.
   - Clear introduction of Bed Prasad Bhusal, including his roles and affiliations.
   - Call-to-action button leading to the About section.

### 2. **About Section**
   - Detailed biography with a focus on career achievements.
   - Includes personal details such as city and education.

### 3. **Services Section**
   - Highlights the two main ventures:
     - **B&B Group Pvt. Ltd.**
     - **Sachetana Media Pvt. Ltd.**
   - Interactive links to official websites.

### 4. **Contact Section**
   - Contact information displayed in styled boxes:
     - Email
     - Phone
     - Location
   - Social media links for further engagement.

---

## Technologies Used
- **HTML5** and **CSS3**
- **Tailwind CSS** for utility-based styling.
- **DaisyUI** for pre-designed UI components.
- **FontAwesome** for icons.
- Responsive and interactive design optimized for all devices.
